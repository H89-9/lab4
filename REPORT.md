# Лабораторная работа №4. Ансамбли и полносвязные нейронные сети

## Данные и подготовка

Цель работы — изучить ансамблевые методы машинного обучения, обучить несколько моделей классификации и выбрать наиболее качественную по метрике ROC-AUC.

Использовался датасет `german.csv`, содержащий 1000 записей о клиентах банка и 21 столбец. Целевая переменная — `Creditability`, принимающая значения 0 и 1. Из 1000 клиентов 700 относятся к классу 1, остальные 300 — к классу 0.

В данных отсутствуют пропущенные значения. Для обучения использовались 20 признаков. Категориальные признаки были представлены числовыми кодами из исходного файла.

Данные разделены на обучающую (80%) и тестовую (20%) выборки с параметром `random_state=42` и стратификацией по целевому классу.

Из обучающей части дополнительно выделена валидационная выборка. В результате использовались 600 записей для обучения, 200 для валидации и 200 для итогового тестирования.

Масштабирование признаков не проводилось, поскольку исследуемые ансамблевые модели основаны на деревьях решений.

## Гипотезы и эксперименты

Основная гипотеза заключалась в том, что ансамбли деревьев решений позволят получить высокое качество классификации за счёт объединения нескольких моделей.

Были проверены четыре варианта:

1. **Random Forest 1** — 200 деревьев, максимальная глубина 6, минимальное количество объектов в листе 3.
2. **Random Forest 2** — 300 деревьев, максимальная глубина 8, минимальное количество объектов в листе 2.
3. **Extra Trees** — 300 деревьев, максимальная глубина 8, минимальное количество объектов в листе 2.
4. **Gradient Boosting** — 150 деревьев, скорость обучения 0.05, максимальная глубина 2.

Сначала модели сравнивались на одной валидационной выборке. Затем проводилась пятикратная стратифицированная кросс-валидация на 800 обучающих записях.

Основным критерием выбора модели являлся средний ROC-AUC при кросс-валидации.

Модель Random Forest 2 показала наилучший средний ROC-AUC, поэтому была выбрана для итогового тестирования.

## Метрики

Для оценки использовались ROC-AUC, Accuracy, Precision, Recall и F1.

Результаты на валидационной выборке:

| Модель | ROC-AUC | Accuracy | Precision | Recall | F1 |
|---|---:|---:|---:|---:|---:|
| Random Forest 1 | 0.7883 | 0.7350 | 0.7458 | 0.9429 | 0.8328 |
| Random Forest 2 | 0.7988 | 0.7650 | 0.7719 | 0.9429 | 0.8489 |
| Extra Trees | 0.7871 | 0.7550 | 0.7571 | 0.9571 | 0.8454 |
| Gradient Boosting | 0.7837 | 0.7700 | 0.7831 | 0.9286 | 0.8497 |

Результаты пятикратной кросс-валидации:

| Модель | Средний ROC-AUC | Стандартное отклонение |
|---|---:|---:|
| Random Forest 1 | 0.7773 | 0.0436 |
| Random Forest 2 | 0.7797 | 0.0411 |
| Extra Trees | 0.7773 | 0.0356 |
| Gradient Boosting | 0.7678 | 0.0297 |

Финальные результаты выбранной модели Random Forest 2 на тестовой выборке:

| Метрика | Значение |
|---|---:|
| ROC-AUC | 0.8375 |
| Accuracy | 0.8000 |
| Precision | 0.8049 |
| Recall | 0.9429 |
| F1 | 0.8684 |

Модель правильно классифицировала 160 из 200 тестовых объектов.

## Выбранная модель

В качестве итоговой модели выбран **RandomForestClassifier** со следующими параметрами:

- `n_estimators=300`
- `max_depth=8`
- `min_samples_leaf=2`
- `random_state=42`
- `n_jobs=-1`

Данная модель показала лучший средний ROC-AUC по результатам кросс-валидации.

Увеличение количества деревьев и допустимой глубины по сравнению с первым вариантом Random Forest улучшило качество на использованной валидационной выборке.

После выбора параметров модель была повторно обучена на всех 800 обучающих записях и проверена на 200 отложенных тестовых объектах.

Итоговый ROC-AUC составил 0.8375, что превышает порог 0.80 из задания.

## Выводы и ограничения

В ходе лабораторной работы были изучены и сравнены ансамблевые модели классификации.

По результатам экспериментов наиболее перспективной оказалась Random Forest 2. Она показала лучший средний ROC-AUC при кросс-валидации и достигла ROC-AUC 0.8375 на итоговой тестовой выборке.

Увеличение количества деревьев и изменение их глубины улучшили результат на валидации. Gradient Boosting показал меньший ROC-AUC при выбранных параметрах, несмотря на относительно высокий F1.

Ограничением исследования является небольшой размер датасета и дисбаланс классов: 70% объектов относятся к классу 1. Кроме того, категориальные признаки представлены числовыми кодами, что не всегда является оптимальным способом их обработки.

Различия между средними результатами моделей небольшие, поэтому нельзя утверждать, что Random Forest 2 будет лучшим на любых новых данных.

В дальнейшем можно изучить другие параметры моделей, попробовать отдельное кодирование категориальных признаков и повторную проверку на независимых данных.

## Воспроизводимость

Эксперименты выполнены на Python с использованием библиотек Pandas и scikit-learn.

Основные файлы проекта:

- `ensemble_models.py` — функция обучения выбранной модели и расчёта метрик.
- `experiment_ensemble.py` — подготовка данных и итоговое тестирование.
- `compare_models.py` — сравнение четырёх моделей и кросс-валидация.
- `experiment_results.json` — сохранённые числовые результаты.

Для воспроизводимости использовался `random_state=42`.

Разделение данных: 80% для обучения и 20% для тестирования. Для проверки гипотез из обучающей выборки отдельно выделялась валидационная часть.

Команды для запуска:

```bash
python compare_models.py
python experiment_ensemble.py
```

Выбор окончательных параметров выполнялся на обучающих и валидационных данных. Итоговая тестовая выборка не использовалась для настройки модели.

Полученные метрики сохранены в `experiment_results.json`.
